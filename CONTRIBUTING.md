# Contributing

myKit is a personal project: shared code for my own Mac apps, published as-is.

- **Pull requests are not accepted.** They are closed automatically. This isn't about the quality of your change: the kit only holds what my apps need, and I don't want to maintain code I didn't write. Fork the repo and make it yours — the MIT license allows anything.
- **Bug reports are welcome** as GitHub issues, using the bug template: what you did, what happened, macOS version. Feature requests are closed.
- **No support.** I may fix bugs that affect me; there's no promise of a reply or a timeline.
